# 📊 Sorting Visualizer

> **Watch sorting algorithms come alive.**  
> A fast, colorful, and interactive **Sorting Algorithm Visualizer** built with React.

---

## ✨ Features

- 🔁 **Multiple Sorting Algorithms**
  - Bubble Sort
  - Selection Sort
  - Insertion Sort
  - Merge Sort
  - Quick Sort

- 🌈 **Colorful Animations**
  - Bars change color during comparisons
  - Smooth swap animations
  - Wave / ripple–style motion
  - Final glowing animation when sorting completes

- ⚡ **Speed Control**
  - Ultra-fast visualization
  - Adjustable animation speed slider

- 🎛️ **Interactive Controls**
  - Algorithm selection dropdown
  - Generate new random array
  - Visualize sorting with one click

- 🎨 **Neon + Glassmorphism UI**
  - Dark theme
  - Glowing bars
  - Glass-style buttons & controls

---

## 🛠️ Tech Stack

- **React.js** – UI and state management  
- **JavaScript (ES6+)** – Sorting logic & animations  
- **HTML5** – Structure  
- **CSS3** – Neon UI, animations, glassmorphism  
- **Create React App (CRA)** – Project setup  
- **GitHub Pages** – Deployment
